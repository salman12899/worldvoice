# 🌍 WorldVoice

### Your Voice, Your World.

WorldVoice is a modern, cross-platform voice communication application designed to connect people through real-time voice calls. Talk with friends, create group conversations, and stay connected wherever you are.

---

## 🚀 Features

- 🎙️ **Real-Time Voice Calls** — Communicate with other users.
- 👥 **Group Voice Calls** — Talk together in groups of up to 5 participants.
- 🔇 **Microphone Controls** — Easily mute and unmute your microphone.
- 🎚️ **Audio Monitoring** — Monitor microphone activity and input levels.
- 📱 **Cross-Platform Support** — Android and Windows, with iOS planned.
- ⚡ **Simple Interface** — Designed to make voice communication easy.
- 🌐 **Stay Connected** — Connect with friends and communities.

## 🛠️ Installation

1. Visit the project's Releases page.
2. Download the appropriate build for your device.
3. Install or launch WorldVoice.
4. Open the application and connect with other users.
